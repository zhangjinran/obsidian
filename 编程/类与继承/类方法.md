你现有的 `get_semantic_label_names` 是一个[[静态方法]]，它直接遍历 `SemanticLabel` 枚举。如果将来有子类继承它，静态方法仍然会遍历父类的成员，而类方法则会自动使用子类的成员。

### 类方法版（更灵活）

python

@classmethod
def get_semantic_label_names(cls):
    return [label.name for label in cls]  # 使用传入的 cls

这样，当子类（如果有）调用时，`cls` 就是子类本身，方法会自动返回子类的枚举成员名称，体现了多态性。
