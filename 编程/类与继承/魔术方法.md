# `__call__` 
## 本质
本质上就是把不可调用对象转换为1个可调用体。
## 举例
```
class Counter:     
	def __init__(self):         
		self.cnt = 0      
	
	def add(self):         
		self.cnt += 1         
		return self.cnt      
	
	def __call__(self):         
		self.cnt += 1         
		return self.cnt`




c = Counter()  


print(c.add())  # 调用普通方法 
##

print(c())      # 调用 __call__`


输出：

1 2
```
