# 关键字参数：
```
accelerator: Union[str, Accelerator] = "auto"

```
表示传递参数时，可以采用关键字**accelerator=**  进行传递参数
# **类型注解**
例如：`accelerator: Union[str, Accelerator] = "auto"`  
使用了 Python 的类型注解（type hints），说明参数类型可以是 str 或 Accelerator。
## 前向引用（延迟注解）
```
def func(x: "MyClass"):
    pass
``````
允许`MyClass`还没定义
# **可选类型和联合类型**
丰富[[形参#**类型注解**|类型注解]]的用法
```
[Optional[int]] 等价于 [Union[int, None]]，表示可以是 int 或 None。
[Union[str, Accelerator]]表示可以是 str 或 Accelerator 类型。
```
# 使用*
代表* 后的参数必须使用[[形参#关键字参数：|关键字参数]]传参，不能使用位置参数
# 默认参数
`max_epochs: Optional[int] = None
设`None`为默认参数
