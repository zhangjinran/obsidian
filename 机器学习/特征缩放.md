# 原理
- 特征的范围大小会决定对应参数的取值。
- 因为不同的特征一般会拥有不同的数量级。
- 范围大的特征值选较小的参数。
- 这就使得，在梯度下降时，范围大的特征可选的参数范围较小。所以代价函数的等高线图就是一个椭圆，因而在梯度下降的时候就更难收敛。
- 所以通过特征缩放，将两个特征都缩放到0-1的范围内。所以，就可以得到一个圆形的等高线图，所以梯度下降时就更好收敛
# 如何进行特征缩放
## 除以最大值
特征范围在0-1之间。
## 均值归一化
x=（x-mean）/(max-mean)
## z_score归一化
x=(x-mean)/std
# 使用原则
只有差距较大的时候才需要进行缩放
# 使用效果
使得梯度下降的效果更好。
