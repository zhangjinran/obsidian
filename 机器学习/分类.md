# 特点
只有有限的可选的输出
# 类别
## 二分类
- negative class负类
- positive class正类
## 多分类
使用[[sigmoid#softmax|softmax]]算法，可以进行解决，这是[[分类#逻辑回归|逻辑回归]]的推广算法。
## Multi-label classification
多标签分类问题。所以目标输出不再是一个数，而是一个包含多个数的向量，每个数判断一个标签是否正确
# 算法
## [[逻辑回归]]
针对二分类
## [[sigmoid#softmax|softmax]] regression
针对多分类。
## 多标签分类
- 采用多个神经网络，对于每一个标签分开来进行判断。
- 用一个神经网络，不过输出层的每一个节点分配一个[[sigmoid]]函数。
