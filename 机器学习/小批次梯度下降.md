# 使用
特别大的训练集，如果直接进行向量化运算的话，会非常的慢。所以可以将大训练集拆解成很多个小训练集。将每一个小训练集作为一个完整的向量进行计算。
# 符号表示

- $$x^{(i)}表示第i个训练样例$$
- $$z^{[l]}表示第l层输出的z$$
- $$在这里x^{\{i\}}表示第i个mini-batch（小批次）$$
# 比较
相较于一般的梯度下降也叫批次梯度下降来说，小批次梯度下降的一轮遍历，能实现多次梯度下降。但是前者一轮遍历只能实现一次梯度下降。

# 选择mini-batch的size
- 如果size和训练集的大小相同，也就是size=m。就是普通的梯度下降。
- 如果size=1，这就是随机梯度下降。每一条数据就是一个mini-batch。这样做的话会增大噪声，而且最后的结果只会在最低点附近来回震动，无法收敛到最低点。
- 一般来说size在两者之间，而且把mini-batch的size设置为2的多少次方可以加快运行速度。
