# 相关概念
-  underfit（欠拟合）：不是很拟合训练集
- overfit（[[过拟合]]）
-  generalization（泛化）：就是不仅适应训练集，但是不是严格拟合训练集，还可以适应更广泛的应用。也可以就叫做具just right。


# 判断方法
 绘制[[学习曲线]]，建立[[基线]]水平，以基线水平为标准来判断算法的Jtrain和Jcv是过高还是过低。
# 判断准则
-  高偏差算法会欠拟合，Jtrain会很高，Jcv也会很高。
- [[过拟合|高方差]]算法会过拟合，Jtrain会较低，但是Jcv仍然很高。
- 如果既高方差又高偏差，那么Jtrain会较高，但是Jcv会远大于Jtrain。这种情况可能会出现在，对一部分特征拟合程度较低，但是对另一部分特征拟合程度较高。
- Jtrain较低，Jcv也较低，表明有较好的泛化能力。
