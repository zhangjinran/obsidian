# 核心思想
是，对于一个训练样本，在[[神经网络]]的某一层（通常是 [[机器学习/神经网络/序列模型/transformer/transformer|Transformer]] 中的[[注意力]]层或前馈层之后），对这一个样本的所有特征进行标准化处理。
# 举例说明
比如你有196个单词序列，256个特征，它就会对于每一个单词序列的256个特征进行[[归一化]]处理。
# 公式
$$y = \frac{x - \mathrm{E}[x]}{\sqrt{\mathrm{Var}[x] + \epsilon}} * \gamma + \beta $$
# 注意
- 注意对于训练集、测试集还有[[交叉验证集]]，都要使用相同的均值和方差去处理，也就是都使用训练集计算出来的方差。
- scale可以提高梯度下降的效率。
