# 基本概念
- 序列可以是一段声音，一段文字，也可以是一段代码DNA序列，也可以是一个视频的帧序列。
- 属于监督训练
- 可能输入x是一段序列，也可能输出y是一段序列。
# 符号表示
$$x^{<t>}和y^{<t>}分别表示该元素在序列x和y中的位置$$
$$T^{(i)}_x和T^{(i)}_y分别表示x和y中第i个样例的序列长度$$
# 自然语言中的应用
-  建立词典，比如建立一个有十万个单词的词典
- 然后用一个十万维的向量表示语句序列中的每一个元素。
- 比如在词典中我是第500个元素，那么用来表示这个元素的向量第500个元素就是1，其余元素都是0.
# 为什么不能使用普通神经网络
- 输入和输出会在不同的例子里有不同的长度。
- 参数会非常的多，因为，输入的维度将会是输入序列的长度乘以词典的长度。
