# 举例说明
- 对于每一个特征，每个单词都有着不同的取值，用这些单词在这些特征的取值组成的向量来表示这个单词。
- 比如有300个特征，那么每个单词就是一个300维的向量。
# 实际
- 实际上这种特征是虚拟的没有实际存在的，你只是将一个单词映射到了一个300维空间的一个点上。
- 通过学习，这种算法可以把类似的词用类似的嵌入向量表示。
