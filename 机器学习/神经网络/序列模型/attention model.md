# [[多对多架构|encoder-decoder]]框架改进原因
对于序列很长的一个输入，比如说要求翻译一个很长的句子，那么就会要求编码器记住全部的内容，这样显然会使得模型的性能变差，所以就提出了注意力模型加以改进。
# 基本思想
就是在对于输入序列进行处理时，输出序列的每个时间步，只会考虑序列中的其中一部分。这样就会提高模型的性能。
# 基本结构
![[Pasted image 20260223205715.png]]
**由图片可知，最下面的一部分是由[[双向RNN]]组成的一个编码器，对于编码器提供的结果，每一个时间步的解码器将会利用一组注意力参数a去计算编码器的输出结果中不同时间步的占比，然后以此组合出一个结果c，作为解码器该时间步的输入，然后生成一个结果。**
## 符号解释
$$a^{<t,t^`>}就是y^{t}对于a^{t^`}的注意力占比。y^t是输出序列中第t个输出。a^{t^`}是编码器中第t^`时间步的激活值。$$
