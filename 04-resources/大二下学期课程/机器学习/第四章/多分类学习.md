# 机器学习 — 第四章：多分类学习

## 总结
- **思路**：用多次二分类来实现多分类
- **Softmax**：将多个类别的得分归一化为概率，是多分类交叉熵的基础

## 知识点 1：用多次二分类实现多分类

### 要点
- **基本思路**：将多分类问题拆解为多个二分类子问题

![[Pasted image 20260523150008.png]]

- **常见策略**：
  - **OvO (One vs One)**：每两个类别训练一个分类器，共 $C(C-1)/2$ 个
  - **OvR (One vs Rest)**：每个类别 vs 其余所有类别，共 $C$ 个

![[Pasted image 20260523150036.png]]

### 注意事项
- OvO 需要训练更多分类器，但每个分类器只需用到两个类别的数据
- OvR 训练的分类器更少，但每个分类器面临类别不平衡问题

## 知识点 2：Softmax 函数

### 要点
- **公式**：$\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}$，将 $k$ 个得分映射为概率分布，所有输出和为 1

![[Pasted image 20260523150345.png]]

- **损失函数**：多分类交叉熵损失

![[Pasted image 20260523150502.png]]

### 推导
#### 目标
将二分类的对数几率回归推广到多分类
#### 步骤
1. 对每个类别 $c_i$ 计算线性得分 $z_i = w_i^Tx$
2. 用 Softmax 将得分归一化为概率 $P(c_i|x)$
3. 用多分类交叉熵作为损失函数
4. 梯度下降优化
