# 机器学习 — 第四章：熵的相关知识

## 总结
- **自信息** $I(x) = -\log_2 P(x)$：单个事件的理论最短编码长度
- **信息熵** $H(P) = -\sum P(x)\log_2 P(x)$：真实分布的平均编码下界
- **交叉熵** $H(P,Q) = -\sum P(x)\log_2 Q(x)$：用近似分布 $Q$ 编码真实分布 $P$ 的实际开销
- **KL散度** $D_{KL}(P\|Q) = \sum P(x)\log\frac{P(x)}{Q(x)} = H(P,Q) - H(P)$：两个分布的差异
- **核心关系**：$H(P,Q) = H(P) + D_{KL}(P\|Q)$
- **机器学习中的意义**：最小化交叉熵 = 最小化 KL 散度 = 让模型分布 $Q$ 逼近真实分布 $P$

---

**统一例题**：随机变量只有 A、B。真实分布 $P$：$P(A)=0.9, P(B)=0.1$。近似分布 $Q$：$Q(A)=0.5, Q(B)=0.5$。底数 $\log_2$，单位 bit。

## 知识点 1：自信息 $I(x)$

### 要点
- **定义**：单个事件发生时自带的信息量，等价于该事件理论无损最短编码长度
- **公式**：$I(x) = -\log_2 P(x)$
- 事件概率越大 → 信息量越小 → 所需编码越短
- 必然事件 $P(x)=1$，自信息为 0

### 示例
$I(A) = -\log_2 0.9 \approx 0.1520\ \text{bit}$
$I(B) = -\log_2 0.1 \approx 3.3219\ \text{bit}$
高频符号 A 仅需 0.152bit，低频 B 需 3.322bit

## 知识点 2：信息熵 $H(P)$

### 要点
- **定义**：真实分布 $P$ 下所有符号自信息的期望（平均值）
- **两层含义**：
  - 随机变量固有的平均不确定性
  - **无损编码平均码长的理论下界**
- **公式**：$H(P) = -\sum_x P(x)\log_2 P(x)$
- 熵越大 → 事件概率越平均 → 不确定性越大 → 越难压缩
- 熵越小 → 某一事件概率极高 → 结果基本确定 → 压缩空间极大

### 示例
$H(P) = 0.9 \times 0.1520 + 0.1 \times 3.3219 \approx 0.4690\ \text{bit}$
最优压缩极限：平均每符号最少 0.469bit

### 补充：编码方案对比
- **定长编码** (A=0, B=1)：平均 1.0 bit，远高于熵下界
- **单符号霍夫曼** (A=0, B=10)：平均 1.1 bit，更差
- **双符号霍夫曼**：平均 0.645 bit/符号，批量越大越逼近 0.469

## 知识点 3：交叉熵 $H(P,Q)$

### 要点
- **定义**：用近似分布 $Q$ 设计编码规则，去编码真实服从 $P$ 的数据的实际平均比特开销
- **公式**：$H(P,Q) = -\sum_x P(x)\log_2 Q(x)$
  - 权重由真实分布 $P$ 决定，编码长度由近似分布 $Q$ 决定
- 若 $Q = P$，交叉熵 = 信息熵（达到最小）
- 若 $Q$ 与 $P$ 差异越大，交叉熵越大

### 示例
$H(P,Q) = 0.9 \times 1 + 0.1 \times 1 = 1.0\ \text{bit}$
用均等概率的错误分布编码，平均每符号 1bit，远高于 0.469bit

### 与机器学习的关系
分类损失使用交叉熵：$P$ = 真实标签（one-hot），$Q$ = 模型预测概率
训练目标 = 最小化交叉熵 = 让预测分布 $Q$ 逼近真实分布 $P$

## 知识点 4：KL 散度 $D_{KL}(P\|Q)$

### 要点
- **定义**：用近似分布 $Q$ 代替真实分布 $P$ 时额外的平均比特代价
- **公式**：$D_{KL}(P\|Q) = \sum_x P(x)\log_2\frac{P(x)}{Q(x)} = H(P,Q) - H(P)$
- KL 散度恒 $\geq 0$，当且仅当 $P=Q$ 时为 0
- 数值越大，分布差异越大

### 示例
$D_{KL}(P\|Q) = 1.0 - 0.4690 = 0.5310\ \text{bit}$
用错误分布编码，每符号多浪费 0.531bit

## 知识点 5：完整逻辑链

### 要点
```
自信息 I(x)     ← 单个事件的信息量
     ↓ 求期望
信息熵 H(P)      ← 真实分布的平均编码下界
     ↓ 用 Q 编码
交叉熵 H(P,Q)    ← 实际平均编码开销
     ↓ 减去 H(P)
KL散度 D_KL      ← 两个分布的差距
```

**恒等式**：$\boldsymbol{H(P,Q) = H(P) + D_{KL}(P\|Q)}$

### 在机器学习中的意义
- **最小化交叉熵损失** = 最小化 KL 散度 = 让模型预测分布 $Q$ 逼近真实分布 $P$
- 交叉熵 = 信息熵（固定值）+ KL 散度（可优化）
- 由于 $H(P)$ 不随模型参数变化，优化交叉熵等价于优化 KL 散度
