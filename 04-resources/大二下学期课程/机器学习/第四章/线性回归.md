# 机器学习 — 第四章：线性回归

## 总结
- **定义**：从样本中学习一个线性模型 $g(x)$ 表征自变量和因变量之间的关系
- **学习准则**：最小化均方误差 (MSE)
- **优化方法**：最小二乘法（$X^TX$ 可逆时）或梯度下降法
- **正则化**：岭回归（L2）、套索回归（L1），防止过拟合
- **推广**：广义线性回归（联系函数）、多项式回归（高次项）

## 知识点 1：定义与数学模型

### 要点
- **线性回归**：预测数值型数据的最基础方法，学习线性模型 $g(x)$ 表征解释变量（自变量）和响应变量（因变量）之间的关系

## 知识点 2：学习准则

### 要点
- **目标**：最小化均方误差 (MSE)
![[Pasted image 20260521140154.png]]
![[Pasted image 20260521140245.png]]

### 推导
#### 目标
找到使 MSE 最小的参数 $w$
#### 步骤
1. 构造 MSE 代价函数
2. 对 $w$ 求导，令导数为 0
3. 求解 $w = (X^TX)^{-1}X^Ty$

## 知识点 3：求解方法

### 要点
- **最小二乘法 (OLS)**：$w = (X^TX)^{-1}X^Ty$
![[Pasted image 20260521140504.png]]
- **梯度下降法**：当 $X^TX$ 不可逆时使用，迭代更新参数
![[Pasted image 20260521140807.png]]

### 注意事项
- OLS 有解析解，但要求 $X^TX$ 可逆
- 梯度下降是数值解法，适用于大规模数据

## 知识点 4：正则化

### 要点
- **用途**：在代价函数上加约束，防止过拟合，是结构风险最小化的体现
- **岭回归 (Ridge)**：添加 L2 正则化项 $\lambda \sum w_j^2$，把权重往 0 拉
![[Pasted image 20260521141301.png]]
![[Pasted image 20260521141342.png]]
![[Pasted image 20260521141400.png]]
  - $\lambda$ 太小挡不住过拟合，太大导致欠拟合，需交叉验证选值
- **套索回归 (Lasso)**：添加 L1 正则化项 $\lambda \sum |w_j|$，可将不重要特征的权重变为 0，实现稀疏化
![[Pasted image 20260521142029.png]]

### 注意事项
- L2 正则化压缩权重但不归零；L1 正则化可以将权重归零（特征选择）
- 关联：[[L1正则化和L2正则化比较]]

## 知识点 5：性能度量

### 要点
- **$R^2$ 系数**：$R^2 = 1 - \frac{SSE}{SST}$，越接近 1 拟合优度越高
  - SSE：残差平方和，SST：总方差
  - $SST = SSR + SSE$，$R^2$ = 模型能描述的变化程度占总变化的比例
