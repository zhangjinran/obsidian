# 机器学习 — 第四章：对数几率回归分类器

## 总结
- **模型**：用 sigmoid 将线性输出映射到 $[0,1]$，表示属于正类的概率
- **学习准则**：伯努利型 MLE → 等价于最小化交叉熵
- **交叉熵与熵的关系**：$H(P,Q) = H(P) + D_{KL}(P\|Q)$，最小化交叉熵 = 最小化 KL 散度 = 让模型分布逼近真实分布
- **为什么用交叉熵不用 MSE**：sigmoid + MSE 非凸，难以全局最优；交叉熵是凸函数
- **模型类型**：判别式模型，直接对 $P(c|x)$ 建模

## 知识点 1：模型

### 要点
- **sigmoid 函数**：$\sigma(z) = \frac{1}{1+e^{-z}}$，将线性输出 $z = w^Tx + b$ 映射到概率值
- **模型输出**：$P(y=1|x) = \sigma(w^Tx + b)$

## 知识点 2：学习准则——从 MLE 到交叉熵

### 要点
- **伯努利型似然函数**：与一般似然不同，同时针对两个类别
![[Pasted image 20260523141018.png]]

- **二分类交叉熵损失**：最大化似然等价于最小化交叉熵
![[Pasted image 20260523141415.png]]

### 推导
#### 目标
找到使观测数据最可能的参数 $w$
#### 步骤
1. 构造伯努利似然：$\prod_i P(y_i|x_i)^{y_i}(1-P(y_i|x_i))^{1-y_i}$
2. 取负对数 → 交叉熵损失 $L = -\sum_i [y_i\log\hat{y}_i + (1-y_i)\log(1-\hat{y}_i)]$
3. 梯度下降最小化交叉熵

### 注意事项
- **为什么不用 MSE？** 因为 sigmoid + MSE 非凸，容易陷入局部最优；交叉熵是凸函数
- 线性回归结果与对数几率回归判决界要区分

## 知识点 3：交叉熵与熵的关系

### 要点
- **从信息论角度理解交叉熵损失**：
  - 真实标签分布 $P$（one-hot 编码） vs 模型预测分布 $Q$
  - **交叉熵** $H(P,Q) = -\sum P(x)\log Q(x)$：用 $Q$ 编码 $P$ 的平均开销
  - **信息熵** $H(P)$：真实分布的理论最小编码长度
  - **KL 散度** $D_{KL}(P\|Q) = H(P,Q) - H(P)$：两个分布的差距
- **核心恒等式**：$H(P,Q) = H(P) + D_{KL}(P\|Q)$
- **训练的意义**：由于 $H(P)$ 是常数（由真实标签决定，不随模型变化），最小化交叉熵 = 最小化 KL 散度 = 让模型分布 $Q$ 逼近真实分布 $P$

### 示例
以二分类为例，真实标签 $y=1$（one-hot：$P=[1,0]$），模型预测 $\hat{y}=0.8$（$Q=[0.8,0.2]$）：
- 交叉熵 $= -1\cdot\log0.8 - 0\cdot\log0.2 = -\log0.8 \approx 0.223$
若预测 $\hat{y}=0.5$：交叉熵 $= -\log0.5 = 0.693$
预测越准，交叉熵越小

- 详细推导和完整例题见 [[熵的相关知识]]
- 这就是为什么分类问题用交叉熵比 MSE 更合理——它有明确的信息论解释
