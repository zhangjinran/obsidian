# 机器学习 — 第四章：L1 正则化和 L2 正则化比较

## 总结
- **L2 正则（权重衰减）**：惩罚权重平方，参数只会靠近 0 但不会等于 0，保留全部特征，无稀疏性，仅防过拟合
- **L1 正则（Lasso）**：惩罚权重绝对值，大量不重要权重直接被压缩到严格 0，自动筛除无用特征，兼具防过拟合 + 特征选择

## 知识点 1：L2 正则化（权重衰减）

### 要点
- **损失函数**：$Loss = Loss_{original} + \lambda \sum w_i^2$，惩罚项是权重平方，图像是平滑抛物线
- **为什么只能趋近 0 不能精确等于 0**：
  - 当 $w=0$ 时，惩罚梯度 $\frac{d}{dw}(\lambda w^2)=0$
  - 当 $w$ 非常小但 $\neq 0$ 时，梯度非常微小
  - 梯度下降更新：$w = w - \eta(\nabla Loss_{ori} + 2\lambda w)$，每一步都会压缩权重，但永远不会强制拉到严格 0
- **几何直观**：L2 的等高线是圆形，和损失等高线的交点几乎不会落在坐标轴上（坐标轴代表 $w=0$）

### 结果
- 所有特征都会保留，只是权重变小
- **不会删除任何特征**，不存在稀疏性
- 作用仅抑制大权重、防止过拟合，无法简化特征

## 知识点 2：L1 正则化（Lasso）

### 要点
- **损失函数**：$Loss = Loss_{original} + \lambda \sum |w_i|$，惩罚项是权重绝对值，折线形状
- **为什么能产生严格等于 0 的权重**：
  - $w>0$：梯度 $= +\lambda$；$w<0$：梯度 $= -\lambda$
  - $w=0$ 处梯度存在突变，有很强的"推回 0"的力量
  - 只要权重绝对值小于 $\lambda$，梯度下降会直接把 $w$ 压缩到**精确 0**
- **几何直观**：L1 等高线是菱形，棱角刚好卡在坐标轴上，最优解极易落在坐标轴（对应 $w=0$）

### 推导
#### 目标
理解为什么 L1 能产生稀疏解而 L2 不能
#### 关键 Insight
L2 在 0 点梯度为 0 → 权重只会被压缩但不会归零；L1 在 0 点梯度突变 → 有持续的"推力"将小权重推至严格 0

### 稀疏化的好处
- **剔除无关特征**：权重为 0 等价于特征完全不参与预测，直接从模型里"删掉"
- **节约存储、简化结构**：训练后大量参数是 0，只需保存非零权重
- **自动做特征选择**：非零权重对应的就是真正有用的特征

## 知识点 3：一句话对比

### 要点
| 特性 | L2 正则 | L1 正则 |
|------|---------|---------|
| 惩罚形式 | $\lambda \sum w_i^2$ | $\lambda \sum \|w_i\|$ |
| 权重能否为 0 | 不能，只会缩小 | 能，大量权重精确为 0 |
| 稀疏性 | 无 | 有 |
| 特征选择 | 否 | 自动筛选 |
| 主要作用 | 防过拟合 | 防过拟合 + 特征选择 |
| 适用场景 | 特征较少、都可能有用的场景 | 高维、特征冗余多的场景（基因、文本、传感器） |

### 常见误区
- 稀疏化 = 模型参数向量里大量元素为 0
- L2 永远做不到稀疏
- L1 天然自带特征筛选功能
