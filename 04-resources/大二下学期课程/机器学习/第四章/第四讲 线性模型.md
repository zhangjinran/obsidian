# 机器学习 — 第四章：线性模型

## 总结
本章结构如下：

- **线性回归**：基础回归模型，最小化 MSE，OLS / 梯度下降求解，岭回归和套索回归
- **对数几率回归**：用 sigmoid 将线性输出映射到概率，交叉熵损失，判别式模型
- **多分类学习**：用多次二分类实现多分类（OvO / OvR），Softmax
- **线性判别分析 LDA**：投影使类内近类间远，广义瑞利商，拉格朗日乘数法
- **支持向量机 SVM**：最大间隔超平面，核函数将低维映射到高维
- **L1 与 L2 正则化比较**：L2 缩小权重但不归零，L1 可将权重压缩到严格 0 实现稀疏
- **熵的相关知识**：自信息、信息熵、交叉熵、KL 散度，以及对数几率回归中交叉熵损失的信息论基础
