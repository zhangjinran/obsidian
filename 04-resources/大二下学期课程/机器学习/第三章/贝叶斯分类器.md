# 机器学习 — 第三章：贝叶斯分类器

## 总结
本章各部分的逻辑关系：

- **模型假设**：贝叶斯分类器基于两个决策规则——**最小错误率决策**（比较后验概率）和**最小风险决策**（引入损失矩阵），各自对应不同的判决函数
- **学习准则与优化算法**：无论哪种决策，都需要知道类条件概率 $P(x|c)$，因此核心任务是**参数估计**——主要方法有 **MLE**（把参数当确定量）和 **贝叶斯估计**（把参数当随机变量，引入先验）
- **朴素贝叶斯分类器**：学习准则有所不同——不再估计联合概率密度 $P(x|c)$，而是假设特征条件独立，改为估计**每个特征单独**的条件概率密度 $P(x_j|c)$，大幅简化计算
- **EM 算法**：针对数据**无标记**（存在隐含变量）的情况，属于无监督学习方法。公式还不太理解

## 知识点 1：本章结构

### 要点
```
贝叶斯分类器
│
├─ 模型假设
│  ├─ 最小错误率决策          ← 判决函数：g_i(x) = P(c_i|x)
│  ├─ 最小风险决策            ← 判决函数：g(x) = R(c1|x) - R(c2|x)
│  └─ Neyman-Pearson 决策     ← 判决函数：似然比 Λ(x) > μ
│
├─ 学习准则与优化算法（有标记数据）
│  ├─ 极大似然估计 (MLE)      ← 找使数据最可能的参数 θ
│  └─ 贝叶斯估计              ← 引入先验分布，求后验
│
├─ 朴素贝叶斯分类器
│  └─ 条件独立假设            ← 从联合密度 → 各特征单独密度
│
└─ EM 算法（无标记数据）
   └─ 迭代：E步(猜标签) → M步(估参数) → 收敛
```

### 关键关系
- **模型假设**决定了要算什么（后验概率 / 条件风险 / 似然比）
- **学习准则**决定了怎么算（MLE / 贝叶斯估计）
- **朴素贝叶斯**在准则上做了简化（条件独立），属于同一个框架的变体
- **EM 算法**面对的问题不同（无标记），方法也不同（迭代）
