# 机器学习 — 第二章：模型的性能度量

## 总结
- **分类任务指标**：混淆矩阵 → Accuracy / Precision / Recall / Fb-score → PR 曲线 → ROC / AUC
- **回归任务指标**：MSE / MAE / R² 等，与损失函数相似但目的不同

## 知识点 1：分类任务的性能指标
### 要点
- **混淆矩阵**
  - TP：真正例，FP：假正例，FN：假负例，TN：真负例
![[Pasted image 20260428021345.png]]
- **常见指标**
  - **正确率 (Accuracy)**：$\frac{TP+TN}{P+N}$
  - **错误率**：$\frac{FP+FN}{P+N}$
  - **查准率 / 精度 (Precision)**：$\frac{TP}{TP+FP}$
  - **查全率 / 召回率 (Recall)**：$\frac{TP}{TP+FN}$
  - **$F_\beta$-score**：$\frac{(1+\beta) \cdot P \cdot R}{\beta \cdot P + R}$
### 公式
见上方
### 示例
TP=90, FP=10, FN=5, TN=95 → Acc=92.5%, P=90%, R≈94.7%
### 注意事项
- Accuracy 在类别不平衡时不可靠
- Precision 与 Recall 往往此消彼长

## 知识点 2：PR 曲线与 ROC 曲线
### 要点
- **PR 曲线**：Recall 为横轴、Precision 为纵轴，逐次改变阈值绘制
  - 被完全包住则外圈更优；交叉时比较曲线下面积
  - **平衡点 (BEP)**：P=R 时的取值，越高越优
- **ROC 曲线**：真正率 (TPR) vs 假正率 (FPR)，同样逐次设置阈值
  - **AUC**：曲线下面积，越大越优
![[Pasted image 20260428022252.png]]
### 公式
TPR = TP/(TP+FN)，FPR = FP/(FP+TN)
### 示例
无
### 注意事项
- PR 曲线更适合类别不平衡场景
- ROC 对类别分布不敏感
