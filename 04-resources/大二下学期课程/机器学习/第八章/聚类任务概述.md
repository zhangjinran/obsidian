# 机器学习 — 第八章：聚类任务概述

## 总结
聚类是无监督学习的核心任务，按特定标准将数据集分割成不同的簇，使同簇样本相似度尽可能大、不同簇样本差异尽可能大。

## 知识点 1：聚类的基本概念

### 要点
- **定义**：聚类 (Clustering) 是按照某个特定标准（如距离）把数据集分割成不同的类或簇，使同一簇内数据对象的相似性尽可能大，不同簇间数据对象的差异性也尽可能大
- **与有监督学习的区别**：训练样本没有标签，需要算法自动发现数据结构
- **簇 (cluster)**：相似样本的集合
- **用途**：可作为独立任务（直接输出聚类结果），也可作为数据预处理步骤

## 知识点 2：相似度度量

### 要点
- 距离越小 → 样本越相似

#### 明氏距离 (Minkowski Distance)
$$d(x_i, x_j) = \left(\sum_{k=1}^d |x_{ik} - x_{jk}|^p\right)^{1/p}$$

#### 欧氏距离 (Euclidean Distance)
$p=2$ 时的明氏距离：
$$d(x_i, x_j) = \sqrt{\sum_{k=1}^d (x_{ik} - x_{jk})^2}$$

#### 曼哈顿距离 (Manhattan Distance)
$p=1$ 时的明氏距离：
$$d(x_i, x_j) = \sum_{k=1}^d |x_{ik} - x_{jk}|$$

#### 马氏距离 (Mahalanobis Distance)

**特点**：
- 不受量纲影响，两点间的马氏距离与原始数据的测量单位无关
- 由标准化数据和中心化数据（原始数据与均值之差）计算出的马氏距离相同
- 可以排除变量之间相关性的干扰
- 要求样本协方差矩阵满秩；当总体样本数 $m$ 小于样本维数 $d$ 时，协方差矩阵不可逆

## 知识点 3：性能指标

### 要点

#### 外部指标 (External Index)
将聚类结果与某个"参考模型"（有标签）进行比较。

对数据集 $D = \{x_1, x_2, \dots, x_m\}$，聚类给出的簇划分为 $C = \{C_1, C_2, \dots, C_k\}$，参考模型给出的簇划分为 $C^* = \{C_1^*, C_2^*, \dots, C_s^*\}$。

将样本两两配对考虑，定义：
- $a = |SS|$：在 $C$ 中同簇且在 $C^*$ 中也同簇的样本对
- $b = |SD|$：在 $C$ 中同簇但在 $C^*$ 中不同簇的样本对
- $c = |DS|$：在 $C$ 中不同簇但在 $C^*$ 中同簇的样本对
- $d = |DD|$：在 $C$ 中不同簇且在 $C^*$ 中也不同簇的样本对

**Jaccard 系数 (JC)**：
$$JC = \frac{a}{a + b + c}$$

**FM 指数 (FMI)**：
$$FMI = \sqrt{\frac{a}{a+b} \times \frac{a}{a+c}}$$

**Rand 指数 (RI)**：
$$RI = \frac{2(a+d)}{m(m-1)}$$

#### 内部指标 (Internal Index)
直接考察聚类结果，不利用任何参考模型。

![[Pasted image 20260625145540.png]]

**DBI 指数 (Davies-Bouldin Index)**：
$$DBI = \frac{1}{k} \sum_{i=1}^k \max_{j \neq i} \left(\frac{\text{avg}(C_i) + \text{avg}(C_j)}{d_{\text{cen}}(\mu_i, \mu_j)}\right)$$

> DBI 越小 → 簇内距离越小、簇间距离越大 → 聚类性能越好
