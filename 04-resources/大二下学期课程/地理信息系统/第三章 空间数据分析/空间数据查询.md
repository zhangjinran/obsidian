# 空间数据查询

## 总结
空间数据查询分为属性数据查询（SQL）和空间数据查询（几何检索），两者可组合使用。空间索引用以加速查询，主要包括格网索引、R树、四叉树等。

---

## 知识点 1：数据探查概述

### 要点
数据探查让用户查看数据集总体趋势，进行查询并假设数据集之间可能的关系。

**交互式动态链接可视化**：地图、图形和表格在多视窗中显示并动态链接。从表格中选择记录，图形或地图中自动突出显示相应要素。

### 描述性统计量
- **值域**：最大值与最小值之差
- **中值（中位数）**：按顺序排列的中间数
- **平均值**：$\bar{x} = \frac{1}{n}\sum_{i=1}^n x_i$
- **方差**：$\frac{\sum (x_i - \bar{x})^2}{n}$，衡量数据离散程度
- **标准差**：方差的平方根
- **Z 得分**：$z = (x - \mu)/\sigma$，距离平均数多少个标准差

## 知识点 2：属性数据查询

### 要点
属性数据查询通过处理属性数据获取数据子集，所选子集可在表格中查验、统计图中显示并链接到地图高亮要素。

### SQL 查询
SQL 的基本语法：`SELECT <属性列表> FROM <关系> WHERE <条件>`

### 查询表达式
由布尔表达式和连接符组成。简单布尔表达式包括两个操作数和一个逻辑运算符，如 `Parcel.PIN = 'P101'`。

布尔连接符：**AND、OR、XOR、NOT**

### 运算类型
以完整数据集开始，基本查询运算：
1. 向数据子集中加入更多记录
2. 从数据子集中移除记录
3. 选择一个更小子集

> 添加和移除不是修改表格，而是对筛选条件严格化或宽松化，以扩大或缩小子集。

### 关系数据库查询
在多表中选择相关联的记录。使用前需熟悉数据库整体结构、关系表格联接的关键字以及字段数据词典。

## 知识点 3：空间数据查询

### 要点
空间数据查询通过直接处理空间要素的几何图形来从一个图层检索数据子集，通常使用空间索引加速。

### 由图形选择要素
1. 借助空间索引快速检索被选空间实体
2. 根据空间实体与属性的连接关系得到属性列表

### 由空间选择要素

**简单面、线、点相互关系查询**：
- **面面查询**：与某多边形相邻的多边形
- **面线查询**：某多边形的边界有哪些线
- **面点查询**：某多边形内有哪些点状地物
- **线面查询**：某线经过的多边形
- **线线查询**：与某河流相连的支流
- **线点查询**：某道路上的桥梁
- **点面查询**：某点落在哪个多边形内
- **点线查询**：某结点由哪些线相交而成

## 知识点 4：空间索引

### 格网索引
将研究区域用横竖线条划分大小相等或不等的格网，记录每个格网包含的空间实体。查询时先计算对象所在格网，再快速查询。

### R 树、R+ 树索引
根据地物的最小外包矩形建立。每个结点对应磁盘页和区域，非叶结点的子结点区域都在该结点范围内。

![[Pasted image 20260705204955.png]]

### 四叉树索引
递归地把空间分为四分，可看作格网索引的特例。点四叉树索引点要素，区域四叉树索引线和面。

![[Pasted image 20260705205110.png]]
![[Pasted image 20260705205128.png]]

### 其它空间索引
- **BSP 树**：二叉树，空间逐级一分为二
- **KDB 树**：B 树向多维空间的发展，对点索引有较好动态特性
- **CELL 树**：用凸多边形为划分基本单位，磁盘访问次数比 R 树和 R+ 树少

## 知识点 5：属性与空间关系组合查询

### 要点
空间实体间存在拓扑、顺序、距离、方位等关系。例如查询满足以下条件的城市：
- 在京沪线东部
- 距离京沪线不超过 50 公里
- 人口大于 100 万
- 位于特定多边形区域内

传统 SQL 无法处理空间查询，需要对 SQL 进行扩展。

### 地址匹配查询
根据街道地址查询空间位置和属性信息，利用地理编码输入门牌号码即可知道大致位置和所在街区。常用于社会经济调查、公用事业管理、事故分析等领域。
