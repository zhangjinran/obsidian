# 地理信息系统 — 视域与流域分析

## 总结
- **视域分析**：基于 DEM 判断地表可见性，分为点/线/面三类通视
- **点通视计算**：以 Bresenham 算法生成剖面曲线，比较视线高程与地表高程
- **累计视域**：多观察点可视性的叠加，支持计数与布尔两种运算
- **流域分析**：基于 DEM 和流向勾绘河网与集水区域
- **流域特征提取**：洼地处理 → 流向定义 → 汇流计算 → 河网提取

### 知识点 1：视域与通视分析
#### 要点
- **视域**：从一个或多个观察点可以看见的地表范围
- **视域分析/可视性分析**：提取视域的过程
- 通视分析根据输出维数分为三类：
  - **点的通视**：计算视点与待判定点之间的可见性
  - **线的通视**：已知视点，计算视点的视野问题
  - **面的通视**：已知视点，计算视点能可视的地形表面区域集合

#### 示例
通视问题的五类应用 [Lee, J. (1991)]：
1. 已知一个或一组观察点，找出某一地形的可见区域
2. 欲观察到某一区域的全部地形表面，计算最少观察点数量
3. 在观察点数量一定的前提下，计算能获得的最大观察区域
4. 以最小代价建造观察塔，要求全部区域可见
5. 在给定建造代价的前提下，求最大可见区

### 知识点 2：点通视计算（点对点）
#### 要点
已知视点 V 坐标 (x₀, y₀, z₀)，P 点坐标 (x₁, y₁, z₁)，DEM 为二维数组 Z[M][N]。

计算步骤：
1. 使用 **Bresenham 直线算法**生成 V 到 P 的投影直线点集 {x, y}，K = ||{x, y}||，得到对应高程数据 {Z[k], (k = 1, ... K-1)}，形成 DEM 剖面曲线
2. 以 V 到 P 的投影直线为 X 轴，V 的投影点为原点，求出视线在 X-Z 坐标系的直线方程
   ![[Pasted image 20260707141326.png]]
3. 比较 H[k] 与 Z[k]：若存在 Z[k] > H[k]，则 V 与 P 不可见，否则可见
   ![[Pasted image 20260707141353.png]]

### 知识点 3：线通视与面通视
#### 要点
**点对线通视**（求点的视野）：视野线之外的任何地表点都不可见，视野线内的点可能可见也可能不可见。

基于格网 DEM 的算法：
1. P 点沿 DEM 数据边缘顺时针移动，求出视点到 P 点投影直线上点集 {x, y} 及相应地形剖面 {x, y, Z(x, y)}
2. 计算视点至 Pₖ ∈ {x, y, Z(x, y)}, k = 1,2,...K-1 每个与 Z 轴的夹角：βₖ = arctg((Zₚₖ − Zᵥₚ) / k)
3. 求得 α = min{βₖ}，对应点为视点视野线的一个点
4. 移动 P 点，重复直至回到初始位置

**点对区域通视**：点对点算法的扩展。P 点沿数据边缘顺时针移动，逐点检查视点至 P 点直线上的点是否通视。

### 知识点 4：视线操作与累计视域
#### 要点
- **视线操作**是视域分析的基础。视线是连接观察点和观察目标的线
- 若观察范围内任意一点地表或目标高于视线，则该目标不可视

**累计视域**：
- 单观察点视域地图：取值 1 为可视，取值 0 为不可视
- 多观察点生成的视域图称为累积视域图
- 两种表达方式：计数运算（观察点 +1）和布尔运算

### 知识点 5：流域分析与特征地貌提取
#### 要点
**流域**：具有共同出水口的地表水流经的集水区域。流域分析是指用 DEM 和流向来勾绘河网和流域。

**凹点（洼地）处理**：
- 洼地是流域提取的一大障碍
- 有些是 DEM 生成带来的数据错误，有些表示真实地形（采石场、岩洞）
  ![[Pasted image 20260707142738.png]]

**格网点流向定义**：
- 采用 3×3 窗口按 8 方向搜索计算最大坡向
- 分别为 8 方向赋不同代码（1~9）
- 若为凹点，则值为 5
  ![[Pasted image 20260707142852.png]]

**汇流计算**：流量累积栅格用于计算流向每个元胞的元胞数量

![[Pasted image 20260707142945.png]]

### 知识点 6：流域网提取与河流链路
#### 要点
**流域网提取**：设定阈值，将汇流区面积大于阈值的格网点标识为沟谷点，搜索形成流域网
![[Pasted image 20260707143133.png]]

**河流链路**：各河流段被赋予唯一标识值
![[Pasted image 20260707143145.png]]

**全流域**：用流向栅格和河流链路栅格作为输入。临界值越小 → 河网密度越大 → 流域数目越多 → 每个流域面积越小
![[Pasted image 20260707143459.png]]

### 知识点 7：基于点的流域与泄流点
#### 要点
基于感兴趣点（水文站、水坝、水质监测站）勾绘特定流域，这些点称为泻流点或出水口
![[Pasted image 20260707143537.png]]

#### 注意事项
- 泻流点不在河流链路上 → 导致偏小、不完整的流域
- 解决方法：在用户定义搜索半径内将泻流点接合到河流像元上
  ![[Pasted image 20260707143610.png]]
- 泻流点位于交汇点：上游流域合并为泻流点的流域
- 泻流点位于两交汇点之间：河段流域分为上游和下游两部分，上游部分与更上游流域合并
  ![[Pasted image 20260707143734.png]]

### 知识点 8：影响流域分析的因素
#### 要点
- **DEM 分辨率**：影响流域边界提取精度

- **流向算法**：流向定义方式直接影响汇流计算和流域勾绘结果

- **流量累积临界值**：临界值越小 → 河网密度越大 → 流域数目越多 → 面积越小
