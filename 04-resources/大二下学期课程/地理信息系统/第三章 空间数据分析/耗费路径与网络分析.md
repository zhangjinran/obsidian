# 地理信息系统 — 耗费路径与网络分析

## 总结
- **图论基础**：网络分析建立在图（节点+边）和有向赋权图之上
- **网络要素**：链、结点（障碍/拐点/中心/站点）构成路网基本结构
- **路径分析**：包含静态/动态最佳路径、N条最佳路径、最短/最低耗费路径
- **Dijkstra 算法**：计算有向图中单源最短路径的标号法
- **配置分析**：定位-配置通过目标和约束集解决供需匹配问题
- **最小耗费路径**：基于耗费栅格和 Dijkstra 算法找到像元间最小累积耗费路径

### 知识点 1：图论基本概念
#### 要点
- **图** $G(V, E)$：由点集合 $V$（节点）和点与点之间连线的集合 $E$（边）组成
- **有限图**：节点集 $V$ 与边集合 $E$ 均为有限的图
- 连接两个节点间的边可能不止一条（多重边）
- 连接同一节点的边称为自圈
![[Pasted image 20260707192033.png]]

- **有向图**：边有方向的图；**无向图**：边无方向的图
- **路**：无向图中首尾相接的一串边的集合（如 $\{e_1, e_2, e_4\}$ 可用 $\{v_1, v_2, v_3, v_5\}$ 表示）
- **有向路**：有向图中顺向的首尾相接的一串有向边的集合
- **赋权图**：每条边 $(i, j)$ 赋予一个权数 $\omega(i, j)$
- 权数含义可代表距离、行车时间、加工时间等
![[Pasted image 20260707192046.png]]

### 知识点 2：网络要素与属性
#### 要点
网络的基本组成要素：

- **链（Link）**：网络中流动的管线，如街道、河流、水管，状态属性包括阻力和需求
- **结点（Node）**：网络中链的连接点，如港口、车站、电站，包含几种特殊类型：
  - **障碍（Barrier）**：禁止网络中链上流动的点
  - **拐点（Turn）**：出现在网络链中的分割结点上，状态属性有阻力（如拐弯时间、限制）
  - **中心（Center）**：接受或分配资源的位置（如水库、商业中心、电站），状态属性包括资源容量和阻力限额
  - **站点（Stop）**：路径选择中资源增减的结点（如库房、车站），状态属性有资源需求

#### 注意事项
- 路网的属性数据包括：链路阻抗、转弯阻抗、单行道、天桥和地下通道

### 知识点 3：网络分析 — 路径分析
#### 要点
1. **静态求最佳路径**：在给定每条链上的属性后，求最佳路径
2. **N条最佳路径分析**：确定起点或终点，求代价最小的 N 条路径
3. **最短路径或最低耗费路径**：确定起点、终点和要经过的中间点、中间连线，求最短或最小耗费路径
4. **动态最佳路径分析**：权值随权值关系式变化，可能临时出现障碍点，需动态计算

### 知识点 4：Dijkstra 算法（标号法）
#### 要点
- 用于计算从有向图中任意一个节点到其它节点的最短路径
- 需将网络转换成有向图
- 计算最短路径时权重设为实际距离；计算最佳路径时权重设为时间或费用
- 算法描述：逐步标号，从起点出发不断扩展已确定最短路径的节点集合

### 知识点 5：配置分析（定位-配置）
#### 要点
- 配置衡量公共设施的效率，如消防站、学校或它们的服务空间
- **定位-配置**：通过目标和约束集解决供需匹配问题

### 知识点 6：最小耗费路径分析
#### 要点
- 用耗费栅格定义通过每个像元所需的耗费，找到像元间的最小累积耗费路径
- 所需要素：源栅格、耗费栅格、耗费距离量测和生成最小累积耗费路径的算法

**源栅格**：定义源像元，仅源像元有像元值，所有其它像元不赋值

**耗费栅格**：定义穿过每个像元的耗费或阻抗
- 耗费通常是不同耗费因素的总和
- 耗费可以代表实际或相对耗费
- 耗费因素可根据相对重要性进行加权
- 成本栅格虽为单数据集，但常用来代表多个指标

**耗费栅格构建示例**：
- 影响建造成本的因素包括土地利用类型和坡度
- 需将不同测量系统的数据集重新分类为通用比例
  ![[Pasted image 20260707193059.png]]
- 按影响力百分比设置权重（如坡度 66%，土地利用 34%）
  ![[Pasted image 20260707193121.png]]

#### 注意事项
- 不同测量系统的数据集无法直接比较，必须先重新分类

### 知识点 7：耗费距离量测
#### 要点
- 基于节点-链接像元的表示法
- **横向链接**：从一个像元到另一个像元的耗费距离是两个像元耗费值的平均值
- **对角线链接**：从一个像元到另一个像元的耗费距离是两个像元耗费值平均值的 1.414 倍（即 $\sqrt{2}$）
![[Pasted image 20260707193244.png]]

### 知识点 8：最小累积耗费路径与回溯链接
#### 要点
**最小累积耗费路径**：
- 基于 Dijkstra 算法的迭代过程
- 除最小累计耗费栅格外，其他输出包括方向栅格、配置栅格和最短路径栅格
![[Pasted image 20260707193500.png]]

**回溯链接栅格**：
- 成本距离栅格显示累积成本，但不显示返回哪一个源像元以及如何返回
- **成本回溯链接工具**：返回一个方向栅格，提供从任一像元沿最小成本路径返回最近源的基础道路地图
- 每个像元分配一个代码值（0~8）：
  - 0 表示源位置
  - 1~8 按顺时针方向从右侧开始编码方向
  ![[Pasted image 20260707193732.png]]

#### 示例
- 值为 10.5 的像元前往源（校址）的最小成本路径为沿对角线移动通过值为 5.7 的像元
- 回溯链接栅格显示了从各像元前往最近的源时的行进方向
