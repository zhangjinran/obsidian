# 地理信息系统 — 空间插值

## 总结
- **空间插值**：将离散点测量数据转换为连续数据曲面，包括空间内插（同区域推未知）和空间外推（跨区域推未知）
- **整体拟合**：用全局多项式/回归模型拟合整个研究区，捕捉粗尺度趋势
- **局部拟合**：仅用邻近数据点估计未知值，包括最近邻点法、密度估算、IDW、薄板样条、克里金法
- **克里金法**：地统计学方法，基于变异函数建模空间自相关，可输出预测误差（克里金方差）
- **交叉验证**：比较不同插值方法精度的标准流程，RMS 越小越好

### 知识点 1：空间插值的基本概念
#### 要点
- 空间插值常用于将离散点的测量数据转换为连续的数据曲面，以便与其他空间现象的分布模式进行比较
- **空间内插**：通过已知点的数据推求同一区域其它未知点数据的计算方法
- **空间外推**：通过已知区域的数据，推求其它区域数据的方法

#### 注意事项
- 采样点的空间位置对空间插值结果影响很大，理想情况是在研究区内均匀布点
- 完全规则的采样网络在有规律空间分布模式（如等间隔数或沟渠）时会得到片面结果
- 完全随机采样会导致分布不均，部分区域密集、部分区域缺少

### 知识点 2：整体拟合
#### 要点
**趋势面拟合**：用多项式方程拟合已知点的值，用于估算其他点的值。某种地理属性在空间的连续变化，可以用一个平滑的数学平面加以描述。
![[Pasted image 20260707145242.png]]

**回归模型**：多项式回归的基本思想是用多项式表示线、面，按最小二乘法原理对数据点进行拟合。

#### 注意事项
- 趋势面拟合中，五个方程可化为三个方程化简计算
- 回归模型的理论假设：地理坐标 (x, y) 是独立变量，属性值 Z 也是独立变量且服从正态分布，回归误差与位置无关

### 知识点 3：局部拟合 — 基本流程
#### 要点
局部插值方法只使用邻近的数据点来估计未知点的值，包括四个步骤：
1. 定义一个邻域或搜索范围
2. 搜索落在此邻域范围的数据点
3. 选择表达这有限个点的空间变化的数学函数
4. 为落在规则格网单元上的数据点赋值，重复直到格网上的所有点赋值完毕

#### 注意事项
- 使用局部插值方法需注意：所使用的插值函数、邻域的大小

### 知识点 4：局部拟合 — 最近邻点法（泰森多边形）
#### 要点
- **泰森多边形（Thiessen / Voronoi 多边形）**：只用最近的单个点进行区域插值
- 按数据点位置将区域分割成子区域，每个子区域包含一个数据点，各子区域到其内数据点的距离小于任何到其它数据点的距离
- 连接所有数据点的连线形成 Delaunay 三角形，与不规则三角网 TIN 具有相同的拓扑结构
- GIS 中经常采用泰森多边形进行快速赋值
  ![[Pasted image 20260707150050.png]]

#### 注意事项
- 泰森多边形隐含假设：任何地点的气象数据均使用距它最近的气象站的数据
- 除非有足够多的气象站，否则这个假设不恰当——降水、气压、温度等现象是连续变化的
- 插值结果图变化只发生在边界上，边界内都是均质的和无变化的

### 知识点 6：局部拟合 — IDW（距离倒数插值）
#### 要点
- 综合了泰森多边形的邻近点方法和趋势面分析的渐变方法的长处
- 假设未知点 x₀ 处的属性值是在局部邻域内所有数据点的距离加权平均值
- 加权移动平均方法公式：ẑ(x₀) = Σλᵢ·z(xᵢ)，其中 Σλᵢ = 1
- 权重系数由函数 φ(d(x, xᵢ)) 计算，当 d → 0 时 φ(d) → 1
- 最常见形式是距离倒数加权函数：ẑ(xⱼ) = Σz(xᵢ)·dᵢⱼ⁻ʳ / Σdᵢⱼ⁻ʳ

#### 注意事项
- IDW 是一种精确插值方法
- 假设未知值的点受近距离已知点的影响比远距离已知点的影响更大

### 知识点 7：局部拟合 — 薄板样条函数
#### 要点
- **薄板样条函数（Thin-Plate Splines）**：生成一个通过控制点的表面，并使所有点连接形成的所有坡面的斜度变化最小（Franke 1982）
- 基于生成最小曲率的面来拟合控制点

### 知识点 8：局部拟合 — 克里金法
#### 要点
- 克里金法是一种用于空间插值的地统计学方法
- 与其他插值方法相比，克里金法可用估计的预测误差来评估预测的质量
- 克里金法假设空间变异包括三种影响因素：
  - 表征区域变量变异的空间相关因素
  - 表征趋势的"漂移"或结构
  - 随机误差
- 对几种影响的不同解释，形成不同的克里金法：普通克里金、泛克里金等

#### 注意事项
- 详见 [[克里金法详细介绍]]

### 知识点 9：空间插值方法的比较
#### 要点
- 基于相同数据，不同的插值方法将生成不同的插值结果；相同方法、不同参数值也会得出不同预测值
- **反距离权重法（IDW）**：对邻域中样本数据点取平均值，近点权重越大
- **克里金法**：高级地统计过程，生成估计表面之前需对空间行为进行全面研究
- **样条函数法**：使用最小化整体表面曲率的数学函数，生成平滑表面
- **趋势面法**：全局多项式插值，用多项式定义的平滑表面拟合样本点，捕捉粗尺度模式

**交叉验证**：比较插值方法的常用统计技术，重复操作：
1. 从数据集中除去一个已知点的测量值
2. 用保留点的测量值估算除去点的值
3. 比较原始值和估算值，计算预计误差

**RMS（均方根）**：
- 插值方法效果越好，RMS 值越小
- 较好的克里金方法，均方差较小，且标准均方根接近 1
- 标准 RMS 只适用于克里金法（需用变异计算）
- 标准化 RMS 需要用估算值的方差

**分组验证**：将已知点分成两组——一组用于建模，另一组用于检测模型准确度
