# 地理信息系统 — 地理编码与动态分段

## 总结
- **地理编码**：将邮政地址转换为数字地理坐标（经纬度），最常见形式为地址匹配
- **地址匹配三步骤**：预处理（解析+标准化）→ 匹配 → 标绘并插值
- **地理编码变异形式**：交叉点匹配、邮政编码编码、地块编码、反向编码、地名别名编码等
- **线性参照**：使用沿测量线状要素的相对位置存储地理位置
- **动态分段**：基于线性参照，在不分割基础线要素的前提下定位并显示事件

### 知识点 1：地理编码的基本概念
#### 要点
- **地理编码**：将基于文件的邮政地址数据转换为数字地理坐标（如成对的经度和纬度）
- **地址地理编码（地址匹配）**：最常见形式，将街道地址用点要素表示在地图上
- 通过比较地址与参照数据库中的数据来确定街道地址的位置

地理编码参照数据库由街道地图和街道属性组成，包括每个街段的：
- 街道名称
- 街道两侧的起始地址号码
- 每一侧的邮政编码

### 知识点 2：地址匹配流程
#### 要点
地址匹配过程使用地理编码引擎将街道地址转换到地理坐标系统，包含三个步骤：

1. **预处理**：包括解析和地址标准化
   - 例如："630 S. Main Street, Moscow, Idaho 83843-3040"
     - ① 街道编码 (630)
     - ② 朝向前缀 (S or South)
     - ③ 街道名称 (Main)
     - ④ 街道类型 (Street)
     - ⑤ 城市名称 (Moscow)
     - ⑥ 州名 (Idaho)
     - ⑦ 邮政编码（5+4编码）(83843-3040)
   - 标准化处理缩写：Ave → Avenue，N → North，3rd → Third 等

2. **匹配**：在参照数据库下将地理编码引擎和地址相匹配
   - 首先确定街道段位置
   - 然后在该地址所在位置进行插值（如地址 620，则在街道上线性内插出位置）
     ![[Pasted image 20260707185432.png]]

3. **标绘**：把地址作为点要素标注在图上，在所在范围内进行插值

#### 注意事项
- 并非所有地址都有如上完整的结构，标准化是必要环节
- 为应对地址数据库或地址表的错误，地理编码引擎能够放宽匹配条件选项，使用评分系统量化匹配质量
- 鉴于匹配选项众多，可能需要多次运行地理编码程序

### 知识点 3：偏移标注选项
#### 要点
GIS 软件包提供两种偏移方法：
- **端点偏移**：使地理编码的点偏离街段的端点
- **侧向偏移（旁向偏移）**：使地理编码的点置于街段一侧

### 知识点 4：地理编码的变异形式
#### 要点
- **交叉点匹配（街角匹配）**：将地址数据与图上的街道交叉点进行匹配
- **邮政编码地理编码（ZIP code geocoding）**：将邮政编码与它的几何中心位置相匹配
- **地块地理编码（Parcel-level geocoding）**：匹配地块编号与地块几何中心位置，若地块数据库可用还可绘制地块边界线
- **反向地理编码（Reverse geocoding）**：将点的经纬度位置转换成描述性的地址
- **地名别名地理编码（Place name alias geocoding）**：匹配地名（如带有街道地址的有名餐厅或博物馆）与街道地址，定位后描绘为点要素
- **照片地理编码**：在照片上附带定位信息

- 距离测量值用于定位沿线的事件

### 知识点 6：动态分段的概念
#### 要点
- **动态分段**：使用线性参照测量系统计算事件表中存储和管理事件的地图位置以及在地图上显示它们的过程
- 术语"动态分段"源于每次更改属性值时无需分割（即"分段"）线要素的理念，可以"动态"定位线段
- 利用动态分段，可将多组属性与现有线状要素的任意部分相关联，而不会影响基础线状要素的几何

核心要素：
- **路径**：线要素（如街道、公路或溪流），具有与其几何特征存储在一起的线性量测系统
- **事件**：沿路径发生的线性参照数据（如限速、交通事故等）

动态分段 (DynSeg) 是对事件表中所存储事件的地图位置（形状）进行计算的过程。执行动态分段过程后会产生一个动态要素类，也就是路径事件源。

### 知识点 7：路径与事件
#### 要点
**路径**：是把一系列线段链接在一起。路径的创建方式有两种：
- **交互式方法**：由图层的数字化或选择现有的线路来组成路径
- **转换方法**：由所有的线要素或由数据查询所选择的要素来创建

路径要素类是具有已定义测量系统的线要素类，测量值可用于沿其线状要素集定位事件、资产和状况。
![[Pasted image 20260707190600.png]]

**事件类型**：
- **点事件**：发生在点的位置上，例如事故与停车标志
- **线事件**：涵盖部分路径的事件，例如路面状况

**事件的创建方式**：
- 由已含有路径标识码和线性量测的现有表格来创建事件表
- 通过对路径沿线的点或多边形要素的定位来创建事件表

### 知识点 8：叠加事件
#### 要点
叠加事件是创建新事件数据的另一种方式，合并两个输入事件表从而创建一个输出事件表。

- **并集**：将所有线性事件在其交点处进行分割，并将它们写入新事件表中
- **交集**：只将叠置事件写入输出事件表中

可以执行线-线叠加、线-点叠加（与点-线相同），甚至点-点事件叠加。
