# 定义
在数学上，注意力函数可以被定义为一个映射，该映射接受一个查询（Query）和一组键值对（Key-Value pairs），然后输出一个聚合后的信息，通常称为**注意力输出（也叫注意力分数）**。这个输出可以理解为查询中的每个时间维度，在该组数据中查询得到的结果。
# 基本概念
- **Query（查询）**: 代表需要获取信息的请求。**（即我们的输入信息，就是我自己本身）**。
- **Key（键）**: 与Query相关性的衡量标准。可以理解为一种类似的权重。但是不是最终的权重，是中间权重
- **Value（值）**: 包含需要被提取信息的**实际数据**。
- **权重（Attention Weights）**: 通过Query和Key的相似度计算得来，决定了从各个Value中提取多少信息。
# 自注意力（self_attention）
## 公式
- Q：查询，矩阵
- K：键，矩阵
- V：值，矩阵
- softmax：归一化函数，将权重归一化到0和1之间。
- d_k：缩放因子，可以稳定梯度。
```cobol
权重 = softmax(Q * K^T / sqrt(d_k))
最终提取信息=权重*V
```
