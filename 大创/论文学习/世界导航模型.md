# 基本功能
- 导航机器人所看到的一张图片和速度还有转向作为输入。
- 然后生成下一阶段，导航机器人视角所看到的图片。
- 未知环境下，能预测的就比较有限，已知环境下预测的内容更加丰富。
- 在已知环境下，可以根据预测的结果与目标图片的相似度比较，来实现导航的目的。
# 特点
- 规划中动态纳入规划条件
- 适应性很强，可以通过动态调整模型的规模，去适应多样的环境。

# 世界模型的优势
### 数据效率与利用无标签数据

- **普通导航：** 通常需要大量的、带有动作标签的“完美数据”来进行模仿学习或强化学习。如果数据中没有包含“动作”指令，模型就很难学习。
    
- **世界模型：** 它可以直接从大量的、没有动作标签的**“哑巴视频”**（如你文中提到的Ego4D数据）中学习。因为世界模型的核心是预测下一帧，它只需要视频本身就能理解场景的物理规律和视觉动态。这让它可以利用互联网级别的海量视频数据来理解世界，然后只需要少量带有动作标签的数据来学习“如何控制”。
    

### 3. 跨实体泛化能力更强

- **普通导航：** 往往与具体的机器人的运动学模型（如转弯半径、速度）强相关。换一个机器人（比如从四足机器人换成轮式机器人），模型可能就需要重新训练。
    
- **世界模型：** 它学习的是**“视觉世界的演变规律”**。即使机器人的执行方式变了，世界变化的规律（比如物体碰撞、光影变化）是不变的。因此，如NWM论文所述，它更容易实现**跨实体（cross-embodiment）**的泛化。只要输入不同机器人的视频，它就能适应不同的身体。
