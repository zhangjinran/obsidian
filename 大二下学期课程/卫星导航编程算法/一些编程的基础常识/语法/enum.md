### 1. 枚举定义的基本结构
```cpp
enum 枚举名 {
    枚举项1 [= 值],
    枚举项2 [= 值],
    ...
};
```
- `enum` 是关键字，声明这是一个枚举。
- `TimeSystemType` 是枚举类型名。
- 花括号内列出所有枚举项（也叫枚举常量），用逗号分隔。

---

### 2. 枚举项的赋值规则
- **可以显式赋值**：如 `Unknown = 0`，将 `Unknown` 明确设为整数 0。
- **自动递增**：如果没有显式赋值，编译器会给它赋值为**前一个枚举项的值 + 1**。  
  所以这里：
  - `Unknown = 0`
  - `GPST` 没赋值，自动为 `0+1 = 1`
  - `BDT` 没赋值，自动为 `1+1 = 2`
  - `UTC` 自动为 `3`
  - `TAI` 自动为 `4`
  - `count` 自动为 `5`

---

### 3. 枚举值的用途
- **`Unknown`** 代表“未知时间系统”，赋值为 0 是常见做法（比如默认值）。
- **`GPST`、`BDT`、`UTC`、`TAI`** 分别表示不同的时间系统类型。
- **`count`** 是一个“计数项”，它的值正好等于前面有效枚举项的个数（这里是 5）。  
  这样做的好处是：可以用 `count` 来表示枚举的范围，例如：
  ```cpp
  // 遍历所有时间系统类型
  for (int i = 0; i < TimeSystemType::count; ++i) { ... }

  // 定义一个字符串数组，索引对应枚举值
  const char* names[TimeSystemType::count] = {
      "Unknown", "GPST", "BDT", "UTC", "TAI"
  };
  ```

---

### 4. 如何使用这个枚举
- **声明变量**：`TimeSystemType t;`
- **赋值**：`t = GPST;` 或 `t = TimeSystemType::GPST;`（C++11 起推荐带作用域写法，但普通枚举也可以直接写 `GPST`）。
- **比较**：`if (t == GPST) { ... }`
