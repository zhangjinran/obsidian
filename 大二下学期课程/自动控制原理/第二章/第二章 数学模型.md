# 建模
就是对于每一个功能框进行一个数学建模，确定每个功能框的输入和输出。
# 数学建模的形式
- 静态关系：代数方程
- 动态关系：
	- 和时间相关：微分方程
	- 还和空间相关：偏微分方程
	- 离散的：差分方程
# 线性系统
满足[[叠加原理]]和齐次性的系统。
# 集中参数
模型只与时间相关，不与空间相关，所以使用微分方程描述。
# 微分方程
- 输出的阶次n一定大于输入的阶次m。
**原因：输出的阶次高，代表输出求导的次数更多，说明输出可以达到更高的变化率，那么这就使得输入无论变的多块，输出的变化都能跟得上。这样因就会导致果。**
- 如果微分方程的形式相似，就说明这两个控制系统是相似的，无论他们俩是电学装置还是机械装置。
- 一般左边是输出右边是输入。

# 非线性的线性化
## 线性化的条件：
小偏差理论或小信号理论。在工程实践中，控制系统一般都有一个额定的工作状态和工作点，当输入变量在工作点附近小范围的变化时，就满足这个条件。也就是在工作点附近可导。
## 线性化的方法：
在给定工作点的邻域将非线性函数展开为泰勒级数，忽略级数中的高阶项后，就可得到只包含偏差的一次项的线性方程。这种线性化方法称为小偏差法。
## 注意
- 会带来误差
- 线性化后的微分方程通常是增量方程
