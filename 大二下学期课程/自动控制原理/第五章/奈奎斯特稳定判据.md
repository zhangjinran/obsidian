# 辅助函数
![[Pasted image 20260412130534.png]]
**辅助函数即闭环特征方程。**

# 特点
- F(s)的分子和分母阶次均为n阶；
- F(s)的零点即为闭环传递函数的极点，即特征方程的根；
- F(s)的极点即为开环传递函数的极点
- 闭环系统稳定的充要条件转化为F(s)的零点均在s平面的左半平面；即零点在s平面的右半平面的个数z=0;
- F(s)和G(s)H(s)只相差1。则曲线的形状不变，坐标轴平移。
