#  自动控制的基本原理
# 基本概念
![[Pasted image 20260305184011.png]]
-  被控对象（对象，控制对象） 在工业生产中，物理量需要被控制的**装置**。
- 被控量 被控对象被控制的物理量，也称为输出信号。
- 给定值 系统输出量应达到的数值，也称为输入信号。
- 测量变送元件 测量系统的被控量并传递给输入端，与给定值比较。
- 控制器（校正装置） 将检测到的偏差信号加以放大和进行能量形式的转换，并决定控制信号是增大还是减小系统的输出量。再通过执行元件，纠正偏差。
## 信号
![[Pasted image 20260305184655.png]]
**自动控制系统的信号表征系统或部件运动的物理量，通常为时间函数**
- 输入信号（参考输入，给定值）
- 输出信号（被控量）
- 反馈信号
- 偏差信号（误差信号）
- 控制信号（控制量）
- 扰动信号（干扰信号）。




# 控制理论的发展概述
# 自动控制系统的分类
## 按信号的传递路径来分：开环控制、闭环控制、复合控制。
### 闭环控制系统
通过反馈回路（采用负反馈）构成闭环，并通过偏差产生控制作用，以求减小或消除偏差的控制系
统。通常说自动控制系统，就是指的闭环控制系统，也称反馈控制系统。
#### 优点
提高系统精度
#### 缺点
结构复杂，参数选择也要进行取舍。
### 开环控制系统
系统的输出端和输入端之间不存在反馈回路。
#### 优点
结构简单
#### 缺点
无法抑制扰动的变化。
### 复合控制系统
![[Pasted image 20260305185944.png]]
是开环和闭环控制相结合的一种控制方式。它是在闭环控制回路的基础上，附加一个输入信号或扰动信号的顺馈 （前馈）通路，用来提高系统的控制精度。
**顺馈通路通常由对输入信号的补偿器或对扰动信号的补偿器组成。**
#### 优点
具有很高的控制精度，可以抑制几乎所有的可量测扰动
#### 缺点
补偿器的参数要求较高

# 对控制系统的基本要求
## 稳定性
是最重要的！！！
### 理解
- 如果一个系统的输出量原来处于静止状态，某一时刻系统有一个扰动输入，当扰动消失后系统的输出量能够逐渐恢复到原来的静止状态，则此系统是稳定的。

- 由于控制系统中一般含有储能元件，导致被控量趋于静止状态的过程会呈现震荡的形式。
- 控制系统的稳定性取决于系统本身的结构和参数，与外加信号无关。
## 动态过程
**被控量处于过渡状态，尚在变化。**
- 单调过程：被控量单调变化，到达新的平衡状态。
- 衰减振荡过程：被控量的动态过程是一个振荡过程，但振荡的幅度不断衰减，到过渡过程结束时，被控量会达到新的稳态值。
- 等幅振荡过程：被控量的动态过程是一个持续等幅振荡过程，始终不能到达新的稳态值。属于临界稳定——不稳定。
- 渐扩振荡过程：被控量的动态过程不但是一个振荡过程，而且振荡的幅值越来越大，大大超过被控量允许的误差范围。这是典型的**不稳定**过程。
##  静态或稳态
**被控量处于平衡状态，为稳态值。这里和稳定性是有区别的，需要注意。对一个稳定的系统而言，当过渡过程结束后，系统输出量的实际值与期望值之差称为稳态误差。而稳态精度的好坏就是由系统的稳态误差去表征的。**
## 动态性能
动态过程是否块的回到稳定状态。
## 稳态性能
稳态误差是大还是小。
