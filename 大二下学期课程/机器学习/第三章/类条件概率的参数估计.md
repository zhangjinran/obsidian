# 需要求得类条件概率的原因

- 证据P(x)是具有特征x的样本的概率，可以从训练集中直接统计。采用诸如比例判决函数决策时，P(x)甚至可以不用计算
- 先验概率P(ck)是样本空间中各类样本的占例，也可以从训练集中统计各类样本占总体的频率而获得
- 因此贝叶斯决策的核心是获得样本空间和标记空间的联合概率分布PX,Y，即获得类条件概率P(X|Y=ck)以设计贝叶斯分类器。因此，贝叶斯分类器的学习变成了对类条件概率的参数估计问题![[Pasted image 20260428201732.png]]
