# 定义
线性回归（linear regression）是机器学习中预测数值型数据的最基础的方法。其目的是从样本中学习一个线性模型𝑔(x)去表征自变量（解释变量）和因变量（响应变量）之间的关系。

# 线性回归的正则化
## 用途
正则化是通过对代价函数加以限制，防止模型过拟合的重要方法，
是结构风险最小化思想的一种具体体现，在机器学习中非常有用。
## 岭回归
- 岭回归在线性回归代价函数上添加了L2正则化项
![[Pasted image 20260521141301.png]]
- 最小二乘解
![[Pasted image 20260521141342.png]]
- 梯度下降迭代
![[Pasted image 20260521141400.png]]
岭回归的    λ是一个“惩罚强度”：
 
- 它会让模型在优化时，主动把特征权重往0拉，避免权重过大导致过拟合；

- 拉得太狠（ λ太大）会欠拟合，拉得太松（ λ  太小）又挡不住过拟合，所以需要交叉验证选一个合适的值。
## 套索回归
- 套索回归在线性回归代价函数上添加了L1正则化项
![[Pasted image 20260521142029.png]]
**不仅可以防止过拟合，还可以将某些不重要特征转化为0，实现稀疏化。**
