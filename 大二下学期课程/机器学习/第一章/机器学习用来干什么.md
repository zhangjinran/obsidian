# 模式识别
## 定义
模式识别是指从样本数据中提取特定模式pattern，并进行分类、回归、聚类或预测的过程。这里的“模式”可以理解为数据中的某种规律性结构或特征（feature）
## 一般步骤
- 1.特征提取：将数据转换为数值特征，用以描述数据的基本属性。例如，在图像识别中提取图像的颜色、亮度、纹理等特征；
- 2.模型构建：根据特征选择合适的方法，对数据进行分类、聚类、预测；
- 3.模型评估：对模型的准确性、鲁棒性、泛化性等进行评估，并反馈到模型构建中进行调整和优化；
# 特征提取
在d 维样本中提取k 个维的新集合，这k 个维是原来d 个维的组合，用以表征原来d维样本。一般d>>k，这一过程也称为维度归约或降维
# 数据生成
对于由m个样本{x1,x2,...,xm}构成的集合（如m个人脸图像），假设它们是彼此独立且都源于某个未知的概率分布q(X) ，如何在不知道q(X) 的情况下构建模型使其也能产生和{x1,x2,...,xm}相似的样本。
# 机器学习
“机器学习是一门学科，致力于研究如何通过计算的手段，利用经验来改善系统自身的性能。在计算机系统中，“经验”通常以“数据”形式存在，机器学习研究的主要内容是在计算机上从数据中产生“模型（model）”
# 深度学习
深度学习更强调将某一事物的海量样本输入机器，让机器通过样本来自己发现特征，预测未知的事物以及生成新的样本。
**和机器学习的区别，机器学习可以手工设计特征，而深度学习需要自己学习和提取特征，深度学习被机器学习所囊括。**
