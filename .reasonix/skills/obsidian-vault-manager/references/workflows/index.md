# Workflow Index

## Available Workflows

| Workflow | 触发方式 | 说明 |
|----------|---------|------|
| Structure Audit | "检查 vault 结构"、"审计目录" | 检查必需目录缺失、非法目录 |
| Note Organization | "整理笔记"、"改写笔记" | 将原始笔记改写成模板格式 |
| Inbox Processing | "处理收件箱"、"清理 inbox" | 将 00-inbox/ 中的笔记归类 |
| Frontmatter Audit | "检查 frontmatter" | 检查笔记的 frontmatter 完整性 |
| Frontmatter Fix | "修复 frontmatter"、"补全 frontmatter" | 自动修复/补全 frontmatter 字段 |
| Template Management | "新增笔记类型" | 新增笔记类型时修改模板和 schema |
