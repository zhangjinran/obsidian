# Note Organization

将原始笔记改写成适合模板的格式，多篇散落笔记可合并为一篇结构化笔记。

## 触发条件

用户说"整理笔记"、"改写笔记"、"按模板整理"、"重写 XX 笔记"。

## 步骤

### 0. 确定笔记文件名
- **不修改笔记文件名**，保持原名
- 如需改名，**必须特别标注给用户过目**

### 1. 通读所有原文
`read_file` 逐篇阅读，确认全部内容

### 2. 确定笔记类型
根据内容选择合适模板（course-review / knowledge-note / meeting / project 等），或由用户指定

### 3. 按模板结构整理
对照 `references/templates.md` 下对应模板文件的结构逐项填充：
- 原文内容逐段搬入对应板块，**不得删减**
- 图片引用 `![[图片名]]` 全部保留
- 关键定义、符号公式、注意事项全部保留
- **整篇重写时用 `write_file` 全覆盖**，不用 `edit_file` 部分编辑，避免新旧混杂

### 4. 如有删减提议
若发现重复、无关或不适内容想删除，**必须特别标注给用户过目**，格式：
```
> ⚠️ 待确认：原文中"XXX"内容与 XX 重复，建议删除。确认后移除。
```

### 5. 填写 frontmatter
按对应模板的 frontmatter 字段填写

### 6. 关联原始笔记
在末尾 `## 关联` 中链接所有原文笔记

### 7. 确认无遗漏
对照原文逐项打勾，确认无信息丢失

### 8. 删除原笔记
确认整理版内容完整无误后，可删除原始散落笔记
