# Obsidian Vault Manager

管理 Obsidian 知识库。当前项目本身就是 Obsidian 库，直接使用 Reasonix 工具操作。

## Available Workflows

- **Structure Audit** — 检查 vault 目录结构
- **Note Organization** — 将笔记改写成模板格式
- **Inbox Processing** — 处理收件箱
- **Frontmatter Audit** — 检查 frontmatter 完整性
- **Frontmatter Fix** — 修复/补全 frontmatter
- **Template Management** — 新增笔记类型
