# 参数
- 待处理字符串, 
- 匹配规则,
- 输出类型：
	 -   无第三个参数：返回**每个匹配字符的索引**（cell 数组，和输入字符串长度一致）；
	 -  带 `'match'`：返回**匹配到的具体字符**（cell 数组）；
	 - 第三个，暂时不需要了解。
    

#### 2. 替换（regexprep）
# 输出
- 无第三个参数：返回**每个匹配字符的索引**（cell 数组，和输入字符串长度一致）；
- 带 `'match'`：返回**匹配到的具体字符**（cell 数组）。

# 用法
## 语法1
```
% 语法1：返回匹配项的索引（最常用） 
indices = regexp(str, pattern); 
```
语法1用法可以和[[编程笔记/python/数据结构/数组#数字数组处理|数字数组处理]]结合使用。
## 语法2
```
% 语法2：返回匹配的具体内容（指定 'match' 输出） 
matches = regexp(str, pattern, 'match');
