# 创建
`a=struct([])`
# 初始化
```
%初始化一个结构体[[[[数组]]]]
a=struct([]);
b=struct([]);
% 第1个文件集（结构体数组，包含2个文件：L1、VFM）
a(1).type = 'L1';
a(1).filePath = 'F:\CALIPSO\L1_001.hdf';
a(2).type = 'VFM';
a(2).filePath = 'F:\CALIPSO\VFM_001.hdf';
```
# 调用
```
a(1)%调用结构体
a(1).type%调用结构体里的元素
`
