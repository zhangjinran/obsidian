# 创建方式
## 空数组
`a=[]`
## ’：‘创建
```b=1：5%创建一个数组
[1,2,3,4,5]%结果
```
在[[循环]]中很有用
## ’[]‘创建


```
a=[1,2]%创建一行二列的行向量

b=[1;2]%创建二行一列的列向量

c=[1,2;3,4]%创建二行二列的矩阵

  

d=[1,2];

e=[a,d]%行拼接

f=[a;d]%列拼接
```

# 处理
## 用数组索引处理

先行后列

```
% 模拟结构体和矩阵字段

ALay_05km.DEM_Surface_Elevation = [

116.1, 39.9, 50; 

116.2, 40.0, 60; 
% 点位3：高程70m

116.4, 40.2, 80]; 


DEM_05km_given = ALay_05km.DEM_Surface_Elevation(:,3)%第三列
```
## [[逻辑数组]]处理
### 生成新数组
```
a=[true,false];

b=[1,1];

b(a)=[1];

%只会留下为true的部分。

```

## 数字数组处理
```
a=[1,2,4]
%构建索引数组
b=[1,2,3,4,5,6]

c=b(a)%获得新筛选后的数组，筛选第一位第二位和第四位。
```
该方法可以和[[#’：‘创建|冒号法]]配合使用
