# 特点：
方便极其方便，你可以理解为，它是一个功能强大的[[数组]]，但是这个[[数组]]的每个单元都可以是一个不同的datastructure
# 创建
## 普通创建
`cell={a,b}`
## 创建空cell
`cell={}`
## 举例

%初始化两个[[结构体数组]]a和b，这里省略

`cell={a,b}`

# {}和（）调用的区别
```
% 对比()和{}的区别

cell(1); % 输出单元格

cell{1}; % 输出结构体数组（单元格里的内容）
```
而且可以对里面东西进行索引。本质上和1个单独的[[结构体数组]]没有任何区别
