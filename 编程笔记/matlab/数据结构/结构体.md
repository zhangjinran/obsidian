## 初始化结构体
`a=struct()`
## 生成一个结构体
```
a.type = 'L1';
a.filePath = 'F:\CALIPSO\L1_001.hdf';
```
## 调用
`a.type`
这样就行。
# 判断是否为空
使用 [[fieldnames]] 函数获取结构体的字段名，该函数对**无字段的结构体**会返回**空[[cell|元胞]]数组 `{}`**，结合 [[isempty]] 即可精准判断，**通用语法**：
```
isempty(fieldnames(yourStruct))
```
