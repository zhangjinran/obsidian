# 创建
## 一般创建方式
和[[编程笔记/matlab/数据结构/数组]]一致，只不过元素为true or false
## 用[[编程笔记/matlab/数据结构/数组]]和不等式进行创建
```
Met_Data_Altitudes = [-50, 0, 100, 200, -10, 300];

  

生成逻辑数组

Met_Flag = Met_Data_Altitudes>0

% Met_Flag的结果：[false, false, true, true, false, true]
```
## [[isnan]]生成
生成0，1数组。
  
# 调用和遍历
# 特点
## 结果为1，0的逻辑数组和true，false组成的逻辑数组，具有明显区别。
- 两者在进行计算时是等价的
- 两者内存占用不等价
- 只有后者能对[[编程笔记/matlab/数据结构/数组#逻辑数组 处理|数组]]进行处理
