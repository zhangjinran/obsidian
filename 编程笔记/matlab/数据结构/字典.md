# 创建
## map创建字典
```
% 方式1：从两个等长数组创建（最常用，键/值可以是字符串/数字） 
keys = {'L1', '05kmCL', '05kmAL'}; % 键（唯一，不能重复） 
values = {'L1', 'd_05kmCL', 'd_05kmAL'}; % 值（可重复） 
type_map = containers.Map(keys, values); 
```
这里的数组是[[cell|元胞]]数组
## 创建空字典，后续添加键值对 
```
empty_map = containers.Map(); empty_map('VFM') = 'VFM'; 
% 新增键值对 
empty_map('05kmCP') = 'd_05kmCP'; 
```


## 指定键/值类型（避免类型混乱）
```
 typed_map = containers.Map('KeyType','char', 'ValueType','char'); 
 % 键值都是字符串 typed_map('05kmAP') = 'd_05kmAP';
```

# 调用和遍历
## 取值
```
% 语法：字典变量(键) 
norm_name1 = type_map('L1'); % 输出 'L1' 
norm_name2 = type_map('05kmCL'); % 输出 'd_05kmCL' 

% 容错：先判断键是否存在，避免报错 
if isKey(type_map, '05kmXX') 
	val = type_map('05kmXX'); 
else 
	val = '默认值'; % 兜底逻辑 
end
```
## 修改 / 新增键值对
```
% 修改已有键的值
type_map('05kmCL') = 'd_05kmCL_new'; % 覆盖原有值

% 新增键值对（直接赋值即可）
type_map('VFM') = 'VFM';
type_map('05kmCP') = 'd_05kmCP';
```
## 删除键值对
```
% 语法：remove(字典变量, 键)
remove(type_map, '05kmAL'); % 删除指定键
% 批量删除（遍历键数组）
keys_to_del = {'05kmCP', '05kmAP'};
for k = 1:length(keys_to_del)
    if isKey(type_map, keys_to_del{k})
        remove(type_map, keys_to_del{k});
    end
end
```
