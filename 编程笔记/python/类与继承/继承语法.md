# super（）
## 用途
可以返回当前父类的对象
## 实例
可以掉用父类的构造函数。
```
class Parent:

	def __init__(self):

		print("Parent init")

  

class Child(Parent):

	def __init__(self):
	
		super().__init__()
		
		print("Child init")
		
c = Child()
# 输出：

# Parent init

# Child init
