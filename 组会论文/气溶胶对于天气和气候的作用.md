# 大陆尺度
在大陆尺度上：
- 气溶胶减少地表太阳辐射（surface dimming）//气溶胶会反射或者吸收太阳辐射，使得地表辐射将减少。
- 减弱陆海热力差  //夏季一般陆地气温高，但由于比热容较小，所以容易受到气溶胶的辐射效应的影响，降温更加显著，从而减弱陆海热力差。

👉 从而 **抑制季风发展**
# 局地尺度
在局地尺度上：

- 改变大气热力稳定度
- 降低气温
- 增强稳定层结
- 削弱风场与环流
# 作为凝结核
气溶胶还可通过作为**云凝结核（CCN）或冰核（IN）**  改变云、对流和降水过程。
# 吸收性气溶胶
吸收性气溶胶（如黑碳、沙尘）：

👉 可触发动力反馈  
👉 甚至可能**增强早期季风**

（这是经典“[[Elevated Heat Pump]]”机制
# 总结
**将自然气溶胶视为季风气候系统的“内在组成部分”**

而不是外部扰动
