# 原理
核心创新在于修改标准RNN架构，使其包含显式的空间变换能力。作者引入了一个空间变换项，使循环单元能够隐式学习如何对齐和整合来自不同视角的观察。

对于SRU-GRU，修改引入了一个空间变换组件：![[Pasted image 20260429233119.png]]
其中$s_t$表示根据当前输入计算的空间变换项，$\odot$操作表示逐元素乘法。这种乘法交互使网络能够执行类似于经典机器人学中齐次变换的隐式空间变换。

SRU-LSTM变体也类似地整合了空间增强：
![[Pasted image 20260429233146.png]]
这些修改使循环单元能够在不同的自我中心视角下保持空间一致性，显著提高了它们构建连贯空间表示以进行导航的能力。
# 理解
类似于空间变换，但是并不是真正的旋转矩阵。因为这里是逐元素乘法，而非旋转矩阵的矩阵乘法，只能对元素做一个权值的放缩。可以用下面的方式理解：

1. CNN / encoder 已经把空间信息编码进 feature
2. 不同视角 → feature 分布不同
3. 用 sts_tst​ 去调制这些 feature
4. → 看起来“对齐”了不同视角

于是他们说：

“我们在做空间变换”
