# 基本概念
好的。**生成对抗网络（GAN，Generative Adversarial Network）** 是一种非常强大的生成模型，核心思想是通过**两个网络的博弈**来学习生成数据。

### 1. GAN 的核心思想：造假者与鉴别者的博弈

GAN 由两个网络组成，它们相互对抗，共同进化：

1.  **生成器：伪造者**
    -   **任务**：接收一个随机噪声向量 \( z \)，尝试生成一张以假乱真的图像（或任何数据），目标是骗过鉴别器。
    -   **目标**：让鉴别器把自己生成的图像判定为“真”。

2.  **判别器：鉴别者**
    -   **任务**：接收图像（可能是真实数据，也可能是生成器生成的假数据），输出一个概率值，判断这张图像是“真实的”（来自训练集）还是“伪造的”（来自生成器）。
    -   **目标**：准确分辨出哪些是真实图像，哪些是生成器生成的假图像。

### 2. 训练过程：猫鼠游戏

这个博弈的过程就像一个动态的“猫鼠游戏”：

1.  **初始状态**：生成器刚开始只会生成纯噪声，判别器很快就能分辨出来。
2.  **交替训练**：
    -   **训练判别器**：给它看一些真实的图像（标签为“真”），以及生成器生成的图像（标签为“假”）。通过反向传播，让判别器学会更好地分辨真假。
    -   **训练生成器**：固定判别器，把生成器生成的图像给判别器看，目标不是让生成器自己变好，而是希望判别器给这些假图像打上“真”的标签。也就是说，生成器的目标是最大化判别器的犯错概率。
3.  **纳什均衡**：经过无数轮对抗，理想情况下会达到一个平衡点：
    -   生成器生成的图像已经极其逼真，完全能够骗过判别器。
    -   判别器面对真假图像，只能随机猜测（输出概率为 0.5），因为它实在分不出来了。
### 3. GAN 的优缺点

| 优点 | 缺点 |
| :--- | :--- |
| **生成质量高**：GAN 能够生成非常清晰、逼真的图像，一度是图像生成领域的 SOTA。 | **训练困难，不稳定**：生成器和判别器需要保持微妙的平衡，否则容易模式崩溃（生成器只生产几种图像欺骗判别器）或[[梯度消失]]。 |
| **不需要显式建模数据分布**：GAN 不需要像变分自编码器那样假设数据分布，而是通过对抗直接学习。 | **难以评估**：没有像 likelihood 这样的明确指标来判断生成器好坏，常用的是主观的人工评价或 Inception Score、FID 等替代指标。 |
| **灵活性强**：可以和各种网络结构结合，用于图像翻译、超分辨率、文本生成图像等多种任务。 | **可能生成模式单一**：如果训练不好，生成器可能会忽视数据的多样性，只生成少数几种模式。 |

# 训练过程
基本流程如下：

- 初始化判别器D的参数 和生成器G的参数 。
- 从真实样本中采样 m个样本 { } ，从先验分布噪声中采样 m个噪声样本 { } 并通过生成器获取 m个生成样本 { } 。固定生成器G，训练判别器D尽可能好地准确判别真实样本和生成样本，尽可能大地区分正确样本和生成的样本。
- **循环k次更新判别器之后，使用较小的[[学习率]]来更新一次生成器的参数**，训练生成器使其尽可能能够减小生成样本与真实样本之间的差距，也相当于尽量使得判别器判别错误。
- 多次更新迭代之后，最终理想情况是使得判别器判别不出样本来自于生成器的输出还是真实的输出。亦即最终样本判别概率均为0.5。**也就是说，最后不论输入的是什么，判断的概率都是0.5.**
