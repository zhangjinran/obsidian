# 公式
原始数列xt
$$v_t=\beta v_{t-1}+(1-\beta)x_t$$$$这里\beta是一个参数，可以自由设置，然后x_t是原始数据，v_t和v_{t-1}是处理后的数据$$

# 注意
- 当β较大时，平均的范围会更广，图像会更平滑，但是相应的图像会像右边移动，且适应新变化的能力会变慢。
![[Pasted image 20260211171344.png]]
**图片中的的蓝点是原始数据，红线是β为0.8的结果，绿线是β为0.98的结果。
- 当β较小时，平均的范围较小，图像会更粗糙，但是适应能力较强。
![[Pasted image 20260211171525.png]]
**图片中的黄线是β为0.5的结果。**
# 对于公式的理解
举例说明，假设β为0.9。
$$v_{100}=0.1*x_{100}+0.1*0.9*x_{99}+0.1*0.9^2*x_{98}......
$$ $$v_t可以近似看作是前\frac{1}{1-\beta}个数据的均值。$$
比如当β等于0.9的时候，vt可以看做前十个数据的均值。因为到第十一个的时候，对于当前数据的影响就太小了。
# 特点
- 高效，占用内存较小。
- 但是估计的结果的准确性比不上直接求平均数的结果。
# 偏差修正
因为如果初始值设置为0，如果直接进行计算的话，前面的的值就会出现偏差。
![[Pasted image 20260211173822.png]]
**比如图像中的紫线就是未进行偏差修正的结果，而使用下面的公式加以修正。偏差修正之后，结果就会变为绿线。**
$$v_t=\frac{v_t}{1-\beta^t}$$
显然当t较大时，这个偏差修正就可以忽略不计了，因为β一定是一个小于1的数字。所以两条线在后来基本上重合。
