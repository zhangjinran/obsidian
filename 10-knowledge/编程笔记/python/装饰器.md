# 实例

```
@my_decorator# 装饰器
def func():
    pass
```
与下方函数等价
```
def func():

	pass

func = my_decorator(func)
```
# 用法
`@` 开头的语句是**装饰器**，用于修饰下面紧跟的函数或类。
# 效果
- `my_decorator` 是一个函数，它接受另一个函数（这里是 `func`）作为参数，并返回一个新的函数（通常是带有额外功能的函数）。
- 这样，`func` 现在就变成了“被装饰过”的函数，调用 `func()` 时会先执行装饰器里的逻辑，再执行原来的 `func` 逻辑。
