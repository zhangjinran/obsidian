# 解包
## 合并字典
```
# 定义两个字典
output = {'a': 1, 'b': 2}
obs_dict = {'b': 3, 'c': 4}

# 使用解包合并字典
merged = {**output, **obs_dict}

print(merged)

# 结果
{'a': 1, 'b': 3, 'c': 4}
```
会自动删除重复值
##  解包到函数参数

字典解包也可以用于将字典中的内容作为函数参数传递：

```
def my_function(a, b, c):     
	print(a, b, c)  

params = {'a': 1, 'b': 2, 'c': 3}  
# 使用解包将字典作为函数参数传递 my_function(**params) 


# 输出: 1 2 3`
``
