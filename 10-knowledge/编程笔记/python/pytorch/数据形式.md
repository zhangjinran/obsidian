# 定义
这个数据形式就是将标量、向量以及更高维度的数据形式，都可以用同一种数据结构tensor表现出来。
# 索引切片
独特的切片形式，设actions的维度为(a,b,c)。这段代码的意思则是取action的第三个维度c的前三个，其它维度都要。中间的冒号是被省略了的。
```
actions[:, :3]#这是取第三个维度c的前三个。

actions[:,:3,:]#这才是取第二个维度b的前三个，而不是
```
