# 参数
# 输出
当函数有多个输出值时，输出参数列表必须要加中括号。
# 用法
```
% 定义一个返回2个输出的函数

function [a, b] = myfun()

a = 1;

b = 2;

end

  

% 用[]接收多个输出（必须加[]）

[x, y] = myfun(); % x=1, y=2

% 也可以把多个输出赋值到一个cell元胞中（和你的代码逻辑一致）

mycell{1} = []; % 初始化元胞

[mycell{1}] = myfun(); % mycell{1}会被赋值为[1,2]（多个输出打包到元胞中）
```
